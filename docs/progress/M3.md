## Nima qilindi

- **Ma'lumotlar (2 migratsiya):** `ScoreEntry` (faqat INSERT, REVERSAL = aniq manfiy, bir marta), `LessonAttendance`,
  `ScoreCriterion`, `ScoreLimitRule` (har scope turi uchun alohida FK ustun, bitta faol qoida), `ScoreSettings`;
  `AssessmentPolicy`/`Version` (e'lon qilingani o'zgarmaydi), `PolicyBinding`, `GradeScale`/`Band`,
  `ManualAssessmentScore` (tarix bilan), `PeriodResult` (FINAL o'zgarmaydi), `PeriodCloseRun`. Invariantlar
  `packages/db/INVARIANTS.md`da.
- **Sof hisob:** `apps/api/src/domain/scoring.ts` (sessiya holati, foizlar, komponentlar, yuqori davrlar, yaxlitlash,
  shkala, policy tekshiruvi), `domain/score-limits.ts` (qoida tanlash, barcha oynalar, hard cap, qolgan ball).
- **Ball qo'yish:** `POST /scores` (bitta yoki batch), o'quvchi bo'yicha lock, idempotency, kechikish
  (`scores.late_entry`), yopiq davr (`assessment.reopen` + sabab), kelmagan o'quvchi, dars avtomatik `HELD`;
  `POST /scores/:id/reverse`; jurnal (`GET /lesson-sessions/:id/journal`) va bulk davomat.
- **Siyosat:** default preset (spec §6) va 5 ballik shkala birinchi kerak bo'lganda yaratiladi; qoralama → e'lon
  (validatsiya) → eski versiya RETIRED; davr faollashganda default bog'lanadi; faol davrga boshqasini qo'llash sabab bilan.
- **Natijalar:** progress (kun/hafta/oy/davr; o'quvchi, vasiy, o'qituvchi, admin doirasi), jurnal jadvali, davr natijalari
  (ochiq davr — jonli, yopiq — FINAL snapshot), yarim yil choraklardan (yopilgan chorak snapshot'idan), umumiy natija.
- **Davrni yopish:** tayyorlash (DRAFT + to'liqmaslik hisoboti: o'qituvchilar bo'yicha baholanmagan darslar, bo'sh
  komponentlar), yopish (FINAL, davr CLOSED, audit), keyingi o'zgarish → "eskirgan", qayta hisoblash → yangi versiya.
- **MANUAL ball** (Q-12) API, **"kim ball qo'ymagan"** hisoboti.
- **UI:** o'qituvchi jurnali (telefonda tez rejim: katta tugmalar, "Hammasi keldi", "Hammaga N ball", bekor qilish,
  "bugun qoldi"), jurnal jadvali, darslar ro'yxatida "Jurnal" havolasi, portalda "Baholar" (fan kartalari, kunlar
  grafigi, tarix), admin "Baholash" (siyosat muharriri jonli yig'indi bilan, limitlar/mezonlar/sozlamalar, shkalalar,
  davrni yopish ustasi, hisobot). Hammasi uz/ru.
- **Demo:** boshlangan choraklar faol, oxirgi 2 haftaga sun'iy ballar va davomat; sinf ichida ismlar takrorlanmaydi.
- **Lokal ishga tushirish:** `pnpm --filter @idrok/e2e local` (M2 oxirida qo'shildi) — Docker/Render/Supabase'siz.
