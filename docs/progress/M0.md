## Eng muhim 5 topilma

1. **Kunlik limit xatosining sababi** — eski `point.routes.ts` `setHours(0,0,0,0)` bilan "bugun"ni server (UTC) vaqtida hisoblagan: Toshkentda 00:00–05:00 orasidagi ballar kechagi limitga tushgan; limit tranzaksiyadan tashqarida sanalgan. Yangi tizim: `schoolDate` (sessiya sanasidan), bitta `time` util, lint taqiqi, lock ostida tekshiruv.
2. **Ball loglari yo'qolishining sababi** — bekor qilish `DELETE` bilan, foydalanuvchi o'chirilganda loglar kaskad o'chirilgan, hisoblagich logdan alohida yuritilgan, route butunlay olib tashlangan, prod tozalash skripti hammasini o'chirgan; joriy coin auditi ham tranzaksiyadan tashqarida. Yangi tizim: append-only ledger (DB trigger), REVERSAL, audit bir tranzaksiyada, `Restrict` FK.
3. **EdexTest test mexanizmi klientga ishonadi va javoblarni oshkor qiladi** — `finishReason`, taymer, buzilishlar hisoblagichi brauzerda; yakunlangan testda API har variantning `isCorrect`ini qaytaradi. Test qismi server-side `TestAttempt` bilan noldan yoziladi.
4. **Parollar qaytariladigan shifrlashda** (admin ko'ra oladi) va taxmin qilinadigan generatsiya; JWT `localStorage`da, refresh/revoke/rate limit yo'q. Yangi tizimda argon2id + httpOnly cookie + rotation.
5. **Qayta ishlatishga arziydigan qism — coin ledger va limit dvigateli**, o'quv yili o'tishi (snapshot + rollback) va SQL invariantlarni avtomatik tekshirish usuli. Ular yangi arxitekturaga g'oya/kod sifatida moslashtiriladi (`createdAt` → `schoolDate`).

Qo'shimcha muhim kuzatuv: spec'larda 5 ta texnik bo'shliq/ziddiyat topildi va sozlama/taklif bilan hujjatlandi (Q-12, Q-14, Q-15, Q-19, Q-46).
