## Nima qilindi

- **Ma'lumotlar (3 migratsiya):** `m4_tests` — `TestType`, `Question`, `QuestionVersion` (append-only), `Test`,
  `TestQuestion`, `TestAssignment`, `TestWindowOverride`, `TestAttempt` (bitta ochiq urinish), `TestAnswer`, `TestEvent`,
  `OfflineResult` (tarix bilan); `m4_test_settings` — `maxQuestionsPerTest`; `m4_history_chain` — tarix ko'rsatkichlari
  unique emas (T-53). Invariantlar `packages/db/INVARIANTS.md`da.
- **Sof funksiyalar** (`apps/api/src/domain/tests.ts`): baholash (4 tur, PARTIAL), javob shakli tekshiruvi, savol
  to'liqligi, contentHash, seed bilan aralashtirish (Fisher–Yates), pool tanlash, deadline, anti-cheat sanash, natija
  ko'rinishi, statistika, mavzu o'zlashtirishi.
- **Savollar banki:** shaxsiy bank + fan bo'yicha ulashish, versiyalar, arxiv, rasm (PNG/JPEG/WebP baytlari bo'yicha),
  Excel shablon/import (preview → commit, mavjud import mexanizmi orqali)/eksport, test turlari (tizim turlari avtomatik).
- **Testlar:** qoralama, qo'lda yoki pool qoidasi, guruh/o'quvchiga berish (o'z guruhlari, shu parallel), e'londan oldingi
  tekshiruv ro'yxati, e'lon (versiyalar qotadi), SCHEDULED → OPEN → CLOSED (kechiktirilgan job + lazy), e'londan keyin
  faqat nom va oyna (`applyToRunning`), yopish (ochiq urinishlar ADMIN_CLOSED), o'chirish/arxiv.
- **Urinishlar:** start (idempotent, tartib va deadline serverda), student DTO'lar (strict), javob (`clientSeq`),
  pozitsiya, anti-cheat hodisalari, topshirish (`finishReason` klientdan olinmaydi), lazy va job bilan TIME_UP,
  qayta ochish (sabab, audit), retake / individual oyna.
- **Offline:** natija jadvali, shkala tekshiruvi, tarix bilan tuzatish, yopiq davr uchun `assessment.reopen` + sabab va
  "eskirgan" belgisi.
- **Davriy baho:** vaznli testlar TESTS komponentiga (COMBINED/SELECTIVE/SEPARATE, LAST/BEST, missed/pending — T-50, T-51);
  T-45 yopildi.
- **Statistika:** test (o'rtacha, median, taqsimot, yakunlanish sabablari, guruhlar, oldingi test), savollar (to'g'ri
  foiz, variantlar ulushi), mavzu o'zlashtirishi (o'quvchi va guruhning eng qiyin mavzulari), o'quvchi test tarixi,
  natijalar Excel eksporti.
- **UI** (uz/ru): o'qituvchi — "Savollar banki" (muharrir 4 tur, rasm, import/eksport), "Testlar" (yaratish, sozlamalar,
  savollar tanlash/pool, e'lon, natijalar, savollar tahlili, urinishlar, qayta ochish, retake, offline kiritish Excel'dan
  qo'yish bilan); admin — barcha testlar, test turlari; o'quvchi (telefon) — "Testlar": topshirish ekrani (bitta savol,
  navigator, server soati bo'yicha taymer, darhol saqlash, internet uzilsa navbat, anti-cheat ogohlantirishi), natija;
  vasiy — farzandining test tarixi; xodimlar uchun o'quvchi profilida test tarixi va mavzular o'zlashtirishi.
- **Yo'l-yo'lakay tuzatishlar:** M3 MANUAL ballni ikkinchi marta tuzatish xatosi (T-53); `Input`/`Select` kengligini
  chaqiruvchi belgilay olmasligi (M3'dagi vazn va qo'lda ball maydonlari ham); sanaga bog'liq `workday` e2e testi.
