- **Migratsiya** `20261102090000_m2_calendar`: `AcademicPeriod`, `SchoolWeek`, `CalendarDay` (+`CalendarDayGrade`), `Shift`, `BellSchedule`/`BellSlot`, `Room`, `ClassGroup.shiftId`. - **API** (`modules/calendar`): davrlar (yaratish, DRAFT'da sana o'zgartirish, faollashtirish, yuqori davr ichida bo'lish), ish haftasi (default dushanba–shanba, Q-02), kalendar kunlari (bitta kun yoki oraliq, parallellar bo'yicha, tahrir/o'chirish — audit bilan), smenalar, qo'ng'iroq jadvallari (smena + `validFrom`, slotlar kesishmaydi), xonalar; sinfga smena. O'qish — `lessons.view` yoki `calendar.manage`, yozish — `calendar.manage` (xonalar — `timetable.manage`). `test/calendar.test.ts` (13).
- **Web**: Admin → Kalendar (oy ko'rinishi: kunni bosib belgilash, oraliq, almashtirilgan ish kuni; davrlar; ish haftasi; smena va qo'ng'iroqlar; xonalar), sinf formasida smena. E2E `calendar.spec.ts` (2).
- **Kichik yaxshilanishlar**: API validatsiya xatosida `refine` kodlari endi `custom` emas, aniq kod (`end_before_start` va h.k.) bo'lib qaytadi; `useSave` umumiy hook; `test/i18n-usage.test.ts` — kodda ishlatilgan har bir statik tarjima kaliti uz.json'da bor (M1'dagi vaqtinchalik skript o'rniga).

### 3-qadam — darslarni hisoblash (`m2/03-lessons`, 2026-11-02)

- **Migratsiya** `20261102150000_m2_lesson_sessions`: `LessonSession` (sana = schoolDate, dars raqami, `startsAt/endsAt` UTC'da, `sequenceNo`, holat, manba, davr, jadval yozuvi, o'rinbosar o'qituvchi — Q-40).   4. `HELD` va "qulflangan" dars bekor qilinmaydi va o'zgarmaydi (`blocked` ro'yxatiga tushadi) ✅ — ball/davomat qulfi M3'da `locked`ga ulanadi;

- **API**: `POST /academic-years/:id/lesson-generation/preview` (qo'shiladi / o'zgaradi / bekor bo'ladi / tegilmaydi, bekor bo'ladiganlar namunasi, ogohlantirishlar: davrsiz kunlar, qo'ng'iroq vaqti yo'q) va `/apply` (`previewHash` — orada nimadir o'zgarsa `PREVIEW_STALE`; bitta transaction, yil bo'yicha advisory lock, audit). `GET /lesson-sessions` (o'qituvchi — o'zi, o'rinbosarligi va guruhlari), `PUT /lesson-sessions/:id/substitute` (Q-40).
